# Korzinka Inventory Management System

## Project Overview

This project is an Inventory Management System for **Korzinka**.

The project documentation describes a system for:
- Product registration and product information management
- Inventory and stock level management
- Recording incoming and outgoing products
- Reports showing current stock levels and product movements

## Project Deliverables

- System / Website: Korzinka Inventory Management System
- Database: Inventory Management Database
- Project Documentation
- Use Case Diagram
- Business Process Model (BPM)
- ERD
- SQL

## Main Customer Requirements

1. Employees can add, edit, delete, and view product information.
2. The system tracks product quantities in each store or warehouse.
3. The system records incoming and outgoing product transactions.
4. The system provides reports for current stock levels and product movements.
