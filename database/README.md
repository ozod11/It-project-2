# Database

This folder contains the database design for the Korzinka Inventory Management System.

## Files

- `schema.sql` — database tables, constraints, stock transaction trigger, and reports.
- `sample_data.sql` — example data and example report queries.
- `ERD.md` — simple ERD description.

## Main tables

1. `products`
2. `locations`
3. `inventory`
4. `stock_transactions`

The design supports the project requirements documented in the IT Project Agreement:
- Product registration and product information management
- Inventory and stock level management
- Incoming and outgoing product transactions
- Reports showing current stock levels and product movements
